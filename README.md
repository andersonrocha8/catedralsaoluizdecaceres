# [AMOSTRA] Página de doação — Catedral São Luiz de Cáceres

Versão de **demonstração** de uma proposta de página de arrecadação para o Projeto de Restauração e Climatização da Catedral São Luiz de Cáceres.

- Marca d'água "AMOSTRA" em toda a página e aviso fixo de versão não oficial.
- Não é indexada por buscadores (`noindex` + `robots.txt`).
- HTML, CSS e JavaScript puros, sem dependências e sem coleta de dados.

A versão oficial será publicada no domínio da paróquia após aprovação.
